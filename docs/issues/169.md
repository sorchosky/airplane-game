# #169 Route spline module

State: open · Labels: agent-ready, size:S, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/169

Part of #167.

## Context

The loop, the valley carve, landmark stations, the river and the golden path all need one shared description of the route. The worker carves terrain from it, so it must be pure TS and fast to query.

## Goal

A pure module describing a closed route as control points, with arc-length sampling and a fast nearest-point query.

## Acceptance criteria

- [ ] `src/world/route.ts`: a closed centripetal Catmull-Rom spline through 2D control points (x, z) with a per-point floor height and valley width. Exposes `pointAt(s)`, `tangentAt(s)`, `length`, and `nearest(x, z)` returning arc length, signed lateral distance, and the interpolated floor height and width.
- [ ] `nearest` uses a uniform grid over precomputed samples, so a query is O(1) on average. Benchmark in a test: 100k queries under 50 ms on CI.
- [ ] Unit tests: closure (point and tangent continuous at s = 0 and s = length), arc-length parameterization within 1% of uniform, nearest accuracy within 1 m against brute force, signed side consistent.
- [ ] No imports from React or Three (worker-safe).
- [ ] A placeholder control-point set (a rough 13.5 km loop from spawn) so the module is testable before #170 lands.

## Out of scope

Choosing the real route (#170). Terrain changes.
