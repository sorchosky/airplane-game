# #156 Front door stage: one persistent layer from title to calibrate

State: open · Labels: size:M, agent-ready, review:visual, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/156

Part of #151.

## Context

`App.tsx` mounts `TitleScreen`, `ControlSelectScreen` and `CalibrateScreen` one at a time by game state, so every step unmounts the previous screen. The continuous front door needs one overlay that stays mounted from `title` through `calibrate` and moves its elements between beats. The game state machine in `src/app/gameStore.ts` stays as is.

## Goal

A `FrontDoorStage` component that owns the overlay from `title` to `calibrate`, maps game state to a beat, and provides the transition plumbing the beat tickets use. This ticket ships the stage with today's visuals and hard cuts between beats.

## Acceptance criteria

- [ ] Pure `beatFor(state, controlMode)` returns `poster | masthead | choose | position | flight` with unit tests covering every `GameState`, including `error` and quit-to-title.
- [ ] `FrontDoorStage` mounts once while the beat is anything but `flight` and hosts the title content, `ControlChoice` (or the existing select screen if #154 hasn't merged) and the calibrate content as children of one tree. `App.tsx` no longer mounts those screens directly.
- [ ] A small Web Animations helper for shared-element moves (FLIP: measure first and last rect, animate transform and opacity), with its rect math as a pure tested function. Transforms and opacity only.
- [ ] A beat-change hook that runs an exit animation for the old beat and an enter for the new one, interruptible (a second change mid-transition reverses cleanly, no stacked animations). Unit test on the scheduling logic.
- [ ] Reduced motion: every beat change is a 200 ms opacity crossfade.
- [ ] Escape and browser back from `choose` return to `masthead`.
- [ ] Behaviour unchanged otherwise: e2e passes for keyboard, touch and replay paths.

## Out of scope

The visual design of each beat and the specific choreography (beat tickets). The world (already live).
