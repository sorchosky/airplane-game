# #175 The golden path becomes the loop

State: open · Labels: size:M, agent-ready, review:visual, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/175

Part of #167.

## Context

The golden path (2026-09-29 decision, `src/world/goldenPath.ts`, `src/world/GoldenPath.tsx`) runs from spawn through three wind rings and a cloud gate to the arch, and completes there. With the loop in place it should follow the route and complete back home.

## Goal

Gates along the whole loop, with a lap completing on re-entry to the home basin.

## Acceptance criteria

- [ ] Rings placed at authored arc lengths along the route (data in `routePoints.ts`), spaced so the next ring is visible from the current one. The cloud gate (rebuilt from cumulus by #163) sits at its station on the route.
- [ ] A lap completes when the plane passes through the return notch after passing every station in order. Completion uses the existing route feedback and audio. A lap counter lives in a store, not React state at frame rate.
- [ ] Still optional and never steers. Flying off the loop never fails anything. Rejoining picks up at the next gate.
- [ ] Pure progress logic (`stationsPassed`, lap completion, rejoin) unit tested.
- [ ] Decision file superseding the 2026-09-29 golden path decision.

## Out of scope

New rewards or scoring.
