# #19 Pose record/replay tool and fake-camera e2e test

State: open · Labels: milestone:M2, size:M, agent-ready, needs-human · https://github.com/sorchosky/airplane-game/issues/19

## Context
Agents can't stand in front of a camera. To test and tune gesture control without the owner, we need (a) recorded pose streams we can replay through the interpreter, and (b) a real video fed to Chromium as a fake camera so CI exercises the whole pipeline (camera → MediaPipe → gesture → flight).

## Goal
A dev recorder, a replay input source, and a Playwright e2e test running on a real clip in CI.

## Acceptance criteria
- [ ] `?debug` adds a Record button (dev only) that captures `poseStore` frames to JSON (timestamps + landmarks) and downloads the file
- [ ] `?input=replay&replay=<name>` loads `tests/fixtures/replays/<name>.json` and feeds frames into `poseStore` on their timestamps, so the real gesture pipeline runs on them
- [ ] A synthetic replay fixture generated from the #16 hand-authored poses (level → bank left → bank right → climb → arms down), so this ticket isn't blocked on the owner's clip
- [ ] A Playwright spec with the replay source asserts the plane's bank sign and altitude change over time (read from `flightStore` exposed on `window` in test builds only)
- [ ] A Playwright spec with Chromium `--use-fake-device-for-media-stream --use-file-for-fake-video-capture=tests/fixtures/video/flight.y4m` goes through calibration to flying and asserts `active` becomes true. Skipped with a clear message if the clip doesn't exist yet.
- [ ] A doc in `tests/fixtures/video/README.md` with the ffmpeg command to convert a phone clip to `.y4m` (640×480, 15 fps, short enough to stay small; use Git LFS if over about 20 MB)
- [ ] Add `npm run e2e` to the CI workflow from #7
- [ ] **Owner step (needs-human):** record a ~20 s landscape clip on the phone's front camera about 2 m away. Walk in, T-pose 3 s, tilt left, tilt right, arms up, arms down, drop arms. Attach it to this issue, and the agent (or a follow-up session) converts and commits it.

## Out of scope
Visual regression testing.
