# #229 Title masthead: soft editorial vignette, tinted text shadow, vertically centred

State: open · Labels: agent-ready, size:S, review:visual, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/229

## Context
Owner direction, 2026-10-04: soften the gradient on the title screen, add a subtle text shadow if
contrast needs it, keep it editorial and natural with the background, never darken the plane, and
vertically centre the type and button.

Current title (`?shot=title`, or the live title at 1920×1080 and 844×390): `TitleScrim` in
`src/app/screens/TitleText.tsx` is a 60vw × 62% box, solid `titleScrim` (navy, 0.6 alpha) to 70%
of its width, then a linear fade, with a vertical mask. On a TV it reads as a dark slab with a
visible vertical edge near 45% width. At 844×390 it reaches the plane. The masthead is top-anchored
(`top: max(space.xl, 8vh)`), leaving the lower 75% of the left column empty. The 2026-10-01 #158
decision set the 0.6 slab as the lowest alpha that held 3:1 with no other assist. This ticket swaps
alpha for a text shadow, so it supersedes #158. The asymmetric layout (#152) stays. Only the
vertical position changes.

## Goal
The masthead feels editorial and part of the scene. Light falls off softly around the type, the
type holds contrast on its own, the plane is never darkened, and the group sits on the optical
centre.

## Acceptance criteria
- [ ] **Remove the box scrim.** Replace with one radial vignette centred on the masthead group:
      `radial-gradient(ellipse 30vw 70vh at <group centre x> <group centre y>, rgba(27,39,72,0.36) 0%, rgba(27,39,72,0.20) 40%, rgba(27,39,72,0.06) 72%, rgba(27,39,72,0) 100%)`.
      Starting values, tune to the contrast gate. Tokenise as `color.titleVignette` (the rgb) and
      `effect.titleVignette` (the gradient). No `backdrop-filter`, it costs fill rate on phones.
- [ ] **Plane stays clean.** Vignette alpha ≤ 0.04 right of 40vw. Measured at `?shot=title`
      (frozen t = 6 s), mean luminance in the plane's screen box changes by ≤ 2% between vignette
      on and off, at 1920×1080 and 844×390.
- [ ] **Tinted text shadow, never black.** Wordmark and Start label get
      `0 1px 2px rgba(27,39,72,0.45), 0 0 24px rgba(27,39,72,0.35)`. The Start outline gets
      `0 0 16px rgba(27,39,72,0.30)` as a box shadow. Token `effect.titleTextShadow`. The 1 px layer
      defines the glyph edge, the 24 px halo gives local contrast without a visible plate.
- [ ] **Contrast gate.** Wordmark and Start label (large text) and Start outline (UI component)
      hold ≥ 3:1 against the frame under them, sampled from rendered pixels under each glyph box,
      for every `lightingPresets` entry and the night key. Extend the #158 test or add an e2e pixel
      sample. The gate fails, not warns.
- [ ] **Vertical centre.** The group (wordmark, rule, Start) centres on the optical centre:
      `top: 50%`, `transform: translateY(calc(-50% - 4vh))`. Left inset unchanged. Spacing inside
      the group stays on the 8 pt grid (wordmark to rule `space.md`, rule to Start `space.lg`, or
      the current tokens if already on grid).
- [ ] **No corner vignette stacking.** If an edge vignette is added for the editorial frame, it
      shows only on tiers without the post-FX vignette (`medium`, `low`), at ≤ 0.15 alpha in the
      corners, and stays clear of the plane box per the luminance gate.
- [ ] The shared-element move into the running head (Choose beat), the intro, reduced motion and
      the portrait prompt all still work. Existing title e2e specs pass.
