# #173 Landmarks at authored route stations

State: open · Labels: size:M, agent-ready, review:visual, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/173

Part of #167.

## Context

`src/world/landmarks.ts` places landmarks by searching 2 to 5 km from spawn (#76). The approved route design (#170, `docs/world-route.md`) assigns each landmark a station and a revealing bend. The placement checks (dry, above water, under 20° slope, silhouette clears the terrain) are still worth keeping as tests.

## Goal

Place each landmark at its station, framed from the route.

## Acceptance criteria

- [ ] Positions come from the stations in `routePoints.ts` (arc length plus lateral offset), not the search. The search code is removed.
- [ ] The #76 footprint and silhouette checks become unit tests asserting every station passes. The sightline check is from the route point 1.5 km before the station, not from spawn.
- [ ] Rendering, outlines, haze behaviour and draw count unchanged.
- [ ] Foliage exclusions follow the new footprints.
- [ ] The `landmark-*` `?shot=` bookmarks updated to frame each landmark from its reveal point. Before and after for each.
- [ ] Decision file superseding #76's placement rule.

## Out of scope

New landmark kinds or models.

`npm run check`. Screenshots. Owner flies the loop and confirms each reveal.
