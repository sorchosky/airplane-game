# #67 E5 · Pose inference in a Web Worker (experiment)

State: open · Labels: size:M, agent-ready, needs-human, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/67

Part of epic #58 (M5 AAA polish pass). Slice E5 in `docs/aaa-backlog.md`. Takes over the worker evaluation from #27.

## Context
MediaPipe runs on the main thread from `requestVideoFrameCallback`. Inference of 15–40 ms on a phone lands inside the 16.7 ms frame budget; whether it actually costs frames depends on the GPU delegate's scheduling, which only a phone trace shows.

## Goal
Decide, with a phone trace, whether inference belongs in a worker, and keep it there only if it wins.

## Acceptance criteria
- [ ] Worker path: `OffscreenCanvas` or `ImageBitmap` transfer of each camera frame to a worker running the Pose Landmarker; results posted back into `poseStore` with the capture timestamp preserved for E1's probe.
- [ ] Main-thread path kept as the fallback and selected automatically where the worker path is unsupported (iOS Safari versions without `OffscreenCanvas` WebGL).
- [ ] `?pose=worker|main` override.
- [ ] Owner step (needs-human): a Chrome performance trace or the E1 probe numbers on the phone for both paths; the decision and the numbers go in `docs/decisions.md`.
- [ ] If the worker does not help, the code is removed rather than left behind a flag.
