# #134 QA6 · Replace mountain pinstriping with soft painterly surface variation

State: open · Labels: size:M, agent-ready, review:visual, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/134

## Context

Batch 3, terrain and ground surfaces. Follow-up to #69. The mountains show conspicuous, repetitive horizontal banding that reads as a digital effect instead of natural painted rock.

Current main combines broad noise and slope-aligned brush breakup with world-Y sine strata, 10–16 m apart at ±6% value, plus distance and derivative fading. The pattern is visibly objectionable even though it is technically antialiased. The owner asks whether JPG surface textures would help.

### QA photo references

- `IMG_0273.jpeg`, primary reference, repeated horizontal stripes across the central peak and broad rock faces at dusk.
- `IMG_0268.jpeg`, pronounced pinstriping on the close left cliff and central night peak.
- `IMG_0271.jpeg` and `IMG_0269.jpeg`, repetition persists in daylight and darker lighting.

Photo filenames refer to the original screenshots supplied with the owner's September 28 QA, reviewed September 29. They are reference identifiers, not repository paths or embedded GitHub attachments.

## Goal

Broad, soft, irregular painterly rock variation that preserves readable mountain forms and the established cel-shaded look.

## Acceptance criteria

- [ ] Remove the visible periodic world-Y sine striping from the default rock appearance. Do not just change stripe spacing or blur the entire image.
- [ ] Reuse the existing world-space macro/brush system for low-contrast, nonperiodic rock breakup. Start with restrained variation within the existing approximately ±4% brush envelope, tune from fixed shots, and document final scale/amplitude.
- [ ] Keep large lit/shadow shapes, slope-based rock/grass separation, snow caps, shoreline coloring, and atmospheric depth readable. Surface detail must not resemble contour lines or override the lighting.
- [ ] Patterns remain anchored in world space through camera motion and streaming. No seams at chunk/LOD boundaries, swimming on slopes, stretched vertical stripes on cliffs, or repeated small-scale noise at flight altitude.
- [ ] Fade/antialias detail as it becomes subpixel. Validate the actual low-quality/DPR 0.75 path shown in QA, as well as medium/high and DPR 1.5.
- [ ] Keep CPU `terrainColorAt` behavior and GLSL rules aligned. Replace obsolete strata-specific expectations with meaningful coverage for bounded modulation, material masks, distance fade, and unchanged terrain-band transitions.
- [ ] Ship a procedural-first correction, consistent with the logged no-ground-textures decision. Do not add a JPG/PNG asset pipeline in this ticket. A file format alone does not address repetition, projection, scale, or lighting.
- [ ] In the PR handoff, explain the bounded fallback if the procedural result remains inadequate, a small original/licensed seamless low-contrast painted/noise map projected in world space, potentially triplanar on cliffs, with mipmaps, repeat suppression, and measured memory/shader cost. That would be a separate owner-reviewed change with a new decision, not unplanned work here.
- [ ] Keep the same terrain mesh and draw-call budget. Compare repeated warmed-up runs on the same route and disclose any material frame-time regression rather than increasing quality to conceal it.
- [ ] Add a decision file superseding the visible sine-strata treatment, and update only art-bible §5's affected surface rule.
