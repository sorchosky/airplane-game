# #132 QA4 · Stabilize the plane outline through dawn, dusk, and night

State: open · Labels: size:M, agent-ready, review:visual, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/132

## Context

Batch 2, silhouette integration. Combines the owner's two reports of the same day-cycle defect, an unexpected cyan-blue outline around 20:00 and a muddy gray outline around 05:30.

Current main's `PlaneModel.tsx` linearly interpolates `planeOutlineDay` toward `planeOutlineNight` using `atmoNight`. The night token is pale blue. This is a concrete inspection lead, not proof that tokens alone explain every rendered edge. Check haze, color conversion, material sharing, and postprocessing as part of the diagnosis. The plane and foliage require different line weights and must not be tuned as one global outline.

## Goal

Neutral, restrained plane linework that retains silhouette clarity throughout the full day cycle, without the cyan dusk cast or muddy dawn interpolation.

## Acceptance criteria

- [ ] Reproduce at pinned `?time=20:00` and `?time=05:30`. Identify the responsible color/material path in the PR before tuning.
- [ ] Use a neutral charcoal/near-black dominant outline at daylight and dawn. Honor art-bible §6's near-black direction instead of defaulting to pure black. At dusk/night, use the minimum neutral edge lift needed for readability, without a saturated cyan-blue border or broad white halo.
- [ ] Avoid a long low-contrast gray midpoint during the night-to-day transition. Put any blend curve or thresholds in named parameters with pure tests and a documented rationale.
- [ ] Keep color transitions continuous through sunrise, sunset, phase keys, and midnight. Do not switch abruptly between dark and light outlines.
- [ ] All plane parts, including articulated stripe/control-surface hulls, use the same intended treatment. Tuning the plane must not recolor cached foliage or landmark outline materials.
- [ ] Retain the current silhouette-weight cap of 3 CSS px. Inspect wings, struts, wheels, and overlaps from the normal chase camera and in a bank. No detached lines, filled-in gaps, or outline flicker.
- [ ] Preserve the existing daytime outline/stripe and nighttime body contrast contracts in tokens/day-cycle tests. Validate final rendered edges against sky, grass, rock, and water at 00:00, 03:30, 05:30, 07:00, 12:00, 18:30, 20:00, and 22:00.
- [ ] No extra rendering pass or draw call. Compare low/medium/high output so color grading cannot silently reintroduce the tint.
- [ ] Add a decision file explaining any changed night-outline palette or interpolation and how it preserves #92's night-readability requirement.
