# #216 e2e: title.spec "desktop select … shows the menu after quitting" times out on Quit to title

State: open · Labels: bug · https://github.com/sorchosky/airplane-game/issues/216

## Problem

`tests/e2e/title.spec.ts:14` ("desktop select offers mouse and keyboard fallback, then shows the menu after quitting") fails on `main` (at 6e2cfb1) in a cloud session:

```
Error: locator.click: Test timeout of 30000ms exceeded.
  - waiting for getByRole('button', { name: 'Quit to title' })
  at tests/e2e/title.spec.ts:25
```

After choosing Mouse and pressing Escape, the "Quit to title" button never appears. Either Escape no longer opens the pause menu in this flow, or the menu is not reachable in time.

It failed on every run, with and without the changes from the blank-world fix. It also failed when run on its own, so it is not a load flake.
