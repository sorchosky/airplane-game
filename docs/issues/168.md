# #168 World map view (`?map`)

State: open · Labels: size:M, agent-ready, milestone:M5 · https://github.com/sorchosky/airplane-game/issues/168

Part of #167.

## Context

Authoring a route through procedural terrain is blind without a top-down view. The owner also needs to review and approve the route from a map, not by flying it.

## Goal

A `?map` debug view that draws a shaded top-down heightmap of the world around spawn with spawn, landmarks, golden path and (once it exists) the route on top.

## Acceptance criteria

- [ ] `?map` renders a 2D canvas (no WebGL scene) of a square area centred on spawn, default 16 km, `?map=<km>` overrides. Heights sampled from the same `heightAt` the worker uses, built off the main thread.
- [ ] Shading: hypsometric bands from the terrain colour tokens plus hillshade from the sun direction, water at `waterLevel` in the water token. Tokens only.
- [ ] Overlays: spawn and heading arrow, each landmark with its label, golden path rings and gate, a 1 km grid with labels. A route overlay hook that draws any closed polyline passed to it.
- [ ] A Playwright helper saves `docs/screenshots/<issue#>-map.png` so later tickets can attach maps.
- [ ] Pure helpers (world to map pixel, hillshade) unit tested.

## Out of scope

Editing the route in the browser.
